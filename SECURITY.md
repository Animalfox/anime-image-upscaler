# Security Policy

## Supported versions

Security fixes are applied to the latest commit on the default branch.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Prefer one of these channels:

1. GitHub **Private vulnerability reporting** for this repository
   (Settings → Code security → Private vulnerability reporting — enable after
   the repo is created; then Security → Report a vulnerability).
2. Open a private security advisory against the repository.

Include:

- a short description of the issue
- steps to reproduce
- affected version / commit
- impact assessment if known

You should receive an acknowledgement within 7 days. After a fix is available,
we will coordinate disclosure timing with you.
